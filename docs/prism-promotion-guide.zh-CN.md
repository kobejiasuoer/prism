# Prism 对外介绍与推广说明

版本：2026-05-24

## 一句话介绍

Prism 是一个完整开源的 AI Native A 股投研与每日决策系统，帮助个人投资者把持仓、观察池、机会筛选、风险提示和复盘记录收敛成每天可执行的行动清单。

## 30 秒介绍

Prism 不是普通股票看板，也不是聊天机器人。它更像一个个人投资决策台：每天先检查数据是否可信，再把当前持仓、观察名单和系统筛出的机会统一整理成“今天该做什么”。系统会给出买入、持有、卖出、观察、仓位建议、风险点和失效条件，并通过 Decision Ledger 记录当时的建议、用户是否执行以及后续结果，帮助用户建立可复盘的交易纪律。

## 2 分钟介绍

Prism 的目标是解决个人投资里最常见的几个问题：

- 信息太碎，看了很多内容，最后还是不知道今天该不该动。
- 持仓、观察股、新机会分散在不同地方，没有统一判断。
- 决策时容易被盘中波动带走，缺少明确的触发条件和失效条件。
- 事后很难复盘，记不清当时为什么买、为什么卖、有没有按计划执行。

Prism 把这些流程合成一个闭环：

1. 通过行情、资金流、候选池、观察池和历史产物生成当日判断。
2. 在“指挥中心”输出今日模式、仓位上限、第一动作、禁止事项和行动分组。
3. 在“持仓管理”里把真实持仓和 Prism 建议对齐，记录成交、未成交、继续观察或放弃。
4. 在“发现/观察”里展示系统筛出的候选、升级条件、失效条件和主线雷达。
5. 在“复盘”里用 Decision Ledger 回看建议、执行和后续结果，沉淀规则假设。
6. 在“设置”里检查数据可信度、运行安全刷新、查看任务和系统健康。

Prism 的关键价值不是“预测一定正确”，而是让每天的判断有结构、有边界、可执行、可追踪。

## 适合怎么定位

对新用户可以这样说：

> Prism 是给 A 股个人投资者用的每日决策助手。它不会替你下单，而是每天帮你把持仓、观察股和新机会整理成一份有仓位、有风险、有失效条件的行动清单，并且把建议和结果记录下来，方便复盘。

对技术用户可以这样说：

> Prism 是一个完整开源的 AI Native 投研系统，包含 Next.js 前端、FastAPI 后端、真实选股/复核工作流、prompt、阈值、任务调度、历史运行产物和脱敏机制。它展示的是一个真实运行的个人投研系统，而不是演示脚本。

对谨慎用户可以这样说：

> Prism 不承诺收益，也不自动交易。它强调数据可信度、仓位约束、风险提示、失效条件和事后复盘，适合想建立交易纪律的人。

## 核心卖点

### 1. 每日行动优先

Prism 默认回答的问题是：今天应该做什么？

它不会把用户淹没在新闻、指标和长报告里，而是先给出行动层：

- 今天偏防守、观察、试错还是进攻。
- 先处理哪只持仓。
- 哪些机会只观察，哪些满足条件才尝试。
- 今天明确禁止什么。
- 最大仓位和风险边界在哪里。

### 2. 一个股票，一个主结论

同一只股票可能来自持仓、观察池或机会池，但 Prism 会尽量合并成统一股票视角：

- 当前主结论
- 建议动作
- 仓位建议
- 核心理由
- 风险和失效条件
- 原始证据来源
- 历史决策记录

### 3. 数据可信度前置

Prism 会在页面上展示 readiness 和 trust 状态。数据过期、交易日不对齐、正式来源未就绪或账户状态异常时，系统会提示先恢复数据链路，而不是让用户直接行动。

### 4. 决策闭环

Decision Ledger 会记录：

- Prism 当时推荐了什么。
- 用户是否成交、未成交、继续观察或放弃。
- 后续 T+1、T+3、T+5 的结果如何。
- 哪些判断可能过严、过松、数据不足或执行没有跟上。

这让 Prism 不只是“给建议”，也能帮助用户长期校准自己的决策系统。

### 5. 完整开源，真实系统

Prism 公开的是实际运行形态：

- Next.js + React 前端
- FastAPI 后端 API
- 选股、AI 二筛、午盘确认、生命周期跟踪脚本
- prompt、阈值和判断规则
- 脱敏后的历史产物、日志和报告
- 一键启动和测试验证

仓库只排除密钥、cookie、登录态、代理凭证和隐私敏感痕迹。

## 目标用户

Prism 当前最适合：

- A 股个人投资者
- 没有成熟投研框架的新手或进阶新手
- 想减少情绪化交易的人
- 想把观察、执行、复盘连起来的人
- 对开源投研系统感兴趣的开发者

暂时不适合：

- 希望系统自动下单的人
- 需要机构级多市场终端的人
- 已经有成熟量化研究平台的人
- 只想看新闻和热点内容的人
- 想要保证收益或确定性荐股的人

## 对外演示建议

### 演示前准备

1. 本地启动 Prism。
2. 确认 `http://127.0.0.1:8000/healthz` 正常。
3. 打开 `http://127.0.0.1:8000/`。
4. 如果页面提示数据未就绪，先到 `Settings` 运行推荐的安全刷新。
5. 准备一只系统里已有记录的股票，用于展示统一股票页。

### 推荐演示路线

1. 打开“指挥中心”

   先讲 Prism 每天先给总控简报，包括今日模式、仓位上限、第一动作、禁止事项、判断链和行动分组。

2. 打开“持仓管理”

   展示真实持仓视角、账户模式、现金、成交记录、未成交记录、对账和“记录已成交/未成交/继续观察/放弃”的闭环。

3. 打开“发现/观察”

   展示候选股票为什么进入观察池，什么条件升级，什么条件失效，以及主线雷达。

4. 用 Command-K 或搜索打开股票详情页

   展示同一只股票的当前结论、Ask 上下文、触发条件、证据来源和 Decision Ledger 历史。

5. 打开“复盘”

   展示系统如何把历史建议变成待复盘样本，如何保存 Review Case，AI 预归因如何辅助但不替代人工定案。

6. 打开“设置”

   展示 readiness、数据恢复向导、后台刷新守护、最近运行、参数编辑和 Decision Ledger 健康。

## 常见问答

### Prism 会自动买卖股票吗？

不会。Prism 只做投研、决策支持、风险约束和记录复盘，不连接券商自动交易。

### Prism 是荐股系统吗？

不应该这样定位。Prism 更适合被介绍成“日常投资决策台”。它会给出候选和建议，但核心价值是纪律、边界、证据和复盘，而不是承诺命中率。

### Prism 适合新手吗？

当前产品方向就是面向 A 股新手和进阶新手。页面会尽量输出可执行动作，而不是只展示专业指标。

### 数据过期时怎么办？

先看“设置”里的今日数据状态和数据恢复向导，运行系统推荐的安全刷新。Prism 不建议在 readiness 阻断时把页面结论当作可执行建议。

### 为什么需要复盘？

因为投资系统真正的进步不来自单次判断，而来自持续知道：哪些建议有效、哪些失败、哪些是没执行、哪些是数据问题。Decision Ledger 就是为这个闭环服务的。

### 开源版本会泄露隐私吗？

仓库公开真实系统结构和脱敏后的历史产物，但不公开 API key、token、cookie、登录态、代理凭证、个人接收人标识和脱敏前本机路径。

## 对外表达边界

推广时建议避免这些说法：

- “保证收益”
- “稳赚”
- “自动交易”
- “替你做投资决定”
- “完全不需要人工判断”
- “实时金融终端替代品”

建议使用这些说法：

- “帮助用户形成每日行动清单”
- “把持仓、观察池和机会筛选统一起来”
- “有仓位建议、风险提示和失效条件”
- “强调数据可信度和交易纪律”
- “记录建议、执行和结果，方便复盘”
- “完整开源的 AI Native 投研系统”
